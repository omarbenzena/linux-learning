# Linux Learning 🐧

This repository documents my hands-on journey learning Linux as part of my
Cloud and DevOps development.

My goal is to build a strong understanding of Linux by practicing concepts
directly in the terminal rather than only studying the theory.

## Topics

As I progress, this repository will cover:

- Linux command-line fundamentals
- Files and directories
- File permissions
- Users and groups
- Processes and services
- Package management
- Networking
- Bash scripting
- System administration
- Troubleshooting
