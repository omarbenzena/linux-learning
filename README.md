# Day 1 - Linux Basics

## Commands I learned

### pwd: This is used to check which is your current directory

### ls: This is used to list the files that are under the current directory

### cd: changes the current directory

### mkdir: is used to create a new directory

### touch: is used to create a new file

### cat: is used to check what contents are inside the file


## Commands I actually ran

pwd
cd
ls
touch hello.txt
echo "Hello from Day 1" > hello.txt
cat hello.txt
mkdir practice
cd practice
pwd
cd


## One thing that confused me

The one thing that confused me was the difference between `ls` and `cd`.
`ls` is used to list the files and directories, while `cd` is used to change
the current directory. I got the hang of it after practicing for a few minutes.

## What I can now do


I can now use the Terminal to perform various actions using simple commands.
I can navigate between directories, create files and folders, list files,
and check the contents of a file without using the graphical interface.
